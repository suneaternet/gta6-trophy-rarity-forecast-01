Forecasts every Grand Theft Auto VI PlayStation 5 trophy's earn rate on Exophase at 2026-11-26T00:00:00Z. main.py (Python 3.13, standard library only) reads a case file, fits a recency-weighted least-squares line of logit(rate) against ln(1 + hours since release) for each trophy, reads the line at the target for the median, and widens the five quantiles with a spread combining a random-walk term that grows with the horizon, the fit's residual scatter, the slope's standard error over the extrapolation distance, and a floor for Exophase's discrete refresh jumps.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
